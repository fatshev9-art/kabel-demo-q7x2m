    Динамометры для контроля натяжения

    Механические динамометры для измерения натяжения каната при монтаже контактной сети, воздушных и кабельных линий. Барабанные и стрелочные исполнения с разными диапазонами шкалы.

      Описание модели

      Механический динамометр для измерения натяжения при монтаже контактной сети. Нагрузка считывается с барабанной шкалы. Корпус закрыт резиновым сильфоном; предусмотрена защита от перегрузки. Диапазон шкалы 0-250. Для выбора исполнения сопоставьте предел измерения с расчётным натяжением каната; погрешность и массу смотрите в таблице характеристик.
