О позиции

Линейный трёхроликовый блок для поддержки кабеля на прямых участках траншеи для кабелей малого и среднего сечения. Устанавливается через каждые 2-3 метра траншеи, чтобы кабель не волочился по грунту и не получал задиров оболочки. Ролики вращаются на закрытых подшипниках, рама складывается и переносится одной рукой. Допустимая нагрузка рассчитана на кабель с запасом по натяжению при протяжке.
